### Quantum-Classical Feature Selection (QAOA Extension)
This project extends the [Womanium AI+Climate]([https://github.com/prathamgupta36/Qgreen]) desertification monitoring pipeline by introducing a hybrid **Quantum Approximate Optimization Algorithm (QAOA)** feature selection layer. To bypass the extreme qubit requirements of raw pixel-level Quantum Image Processing (QIP), I extracted 128-dimensional latent embeddings from a CNN satellite classifier and formulated feature selection as a Quadratic Unconstrained Binary Optimization (QUBO) problem. By balancing feature relevance, correlation redundancy, and a soft cardinality constraint, the QAOA approach achieves a **0.967 mean AUC** using just 4 features—outperforming classical Mutual Information selection while delivering superior run-to-run stability for one case only.
